# WangAnyu 产出物整理规则

## 文件夹结构

```
wanganyu产出物/
├── 项目名-YYYYMMDD/
│   ├── 版本说明.md
│   ├── 产出物文件1
│   ├── 产出物文件2
│   └── ...
└── 项目名-YYYYMMDD/
    ├── 版本说明.md
    └── ...
```

## 命名规则

- **项目文件夹**：`项目名-日期`，如 `调解书整理-20260427`、`语音提醒配置-20260420`
- **版本说明**：每个项目文件夹里必须有 `版本说明.md`，记录：
  - 项目目的
  - 创建日期
  - 文件清单
  - 版本变更记录
