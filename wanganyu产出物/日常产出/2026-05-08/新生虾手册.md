# 新生虾手册 🦞

> 你的 AI 小龙虾刚出生，然后呢？

---

## 30 秒搞懂原理

大模型没有真正的记忆。每次对话开始，它的"大脑"是一块干净的白板。

**OpenClaw 的解决方案：用文件当记忆。**

每次会话开始，小龙虾自动读取几个关键文件，把"我是谁、我服务谁、我之前做过什么"加载到白板上。

**文件写得好 → 有经验的老员工**
**没写 → 什么都不知道的新人**

---

## 四个文件，定义一只龙虾

| 文件 | 职责 | 一句话概括 |
|------|------|-----------|
| **SOUL.md** | 性格说明书 | 名字、角色、说话风格、行为边界。定了就别老改 |
| **USER.md** | 主人档案 | 怎么称呼你、时区、工作背景、沟通偏好 |
| **AGENTS.md** | 行为规范 | 每次会话先读什么、什么时候写日志、什么操作要先问你 |
| **MEMORY.md** | 长期记忆 | 只放最核心的信息：身份、铁律、索引。**控制在 100 行以内** |

---

## 四层记忆，各司其职

光有 MEMORY.md 不够，需要四层配合：

```
第一层：长期记忆（MEMORY.md）
    ↓ 身份、铁律、索引，不怎么变的东西

第二层：主题记忆（wechat-article.md 等）
    ↓ 每个领域一个文件，聚焦且互不干扰

第三层：日志（memory/2026-02-23.md）
    ↓ 当天做了什么、踩了什么坑、下一步是什么

第四层：导航索引（memory/README.md）
    ↓ 快速路由表，收到任务先查表再搜索
```

**为什么分层？** 大模型上下文窗口有限。全塞一个文件，要么加载不完，要么关键信息被噪音淹没。

---

## 五个实用技巧

1. **日志不是流水账** — 只记四样：结果、决策原因、踩坑方案、下一步
2. **文件开头写摘要** — 关键词会被向量索引，搜索命中率大幅提升
3. **一个主题一个文件** — 写文章的规范和做视频的规范别塞一起
4. **建导航索引表** — 确定性路由永远比概率性搜索靠谱
5. **文件名要有语义** — `wechat-article.md` 比 `rules-01.md` 好找一百倍

---

## 五个血泪教训 ⚠️

| 坑 | 解决 |
|----|------|
| 不读规范就动手 | AGENTS.md 写死"先查路由表，读完规范再动手" |
| "我记得"（其实不记得） | 重要信息写进文件，不要相信"记忆" |
| MEMORY.md 变垃圾场 | 每周清理，详细的迁移到主题文件 |
| 规范文件互相矛盾 | 定优先级：主题文件 > MEMORY.md |
| 会话结束不写总结 | AGENTS.md 写死"会话结束前必须更新日志" |

## 实操：从零初始化记忆系统

### 第一步：建目录和核心文件

跟龙虾说：

```
帮我搭建你的记忆系统：
1. 创建 memory/ 目录
2. 创建 MEMORY.md，写入：
   - 我的名字是 [你的名字]
   - 我的时区是 [你的时区]
   - 你的角色是 [你希望它扮演的角色]
   - 你负责帮我 [主要职责]
3. 创建 memory/今天日期.md，写一条"记忆系统搭建完成"
```

### 第二步：写行为铁律（最关键）

跟龙虾说：

```
在你的 AGENTS.md 里加上这段规则：

## 记忆铁律

每次会话开始：
1. 读 MEMORY.md
2. 读 memory/今天.md 和 memory/昨天.md
3. 检查 TASKS.md 有没有待办

工作中：
- 完成一个任务，立刻写日志
- 踩了坑，立刻记录原因和解决方案
- 收到主人反馈，记录反馈和自己的反思

会话结束前：
- 写今天的日志总结
- 重要发现更新 MEMORY.md
```

### 第三步：自检

跟龙虾说：

```
运行记忆自检：
1. 用 memory_search 搜索"我的名字"
2. 用 memory_search 搜索"负责"
3. 确认两个都能搜到结果
```

两个都搜到了 = 记忆系统跑通了 ✅

---

## 故障排查清单

| 故障 | 检查 |
|------|------|
| memory/ 目录不存在 | 让龙虾跑 `mkdir -p memory`，确认目录真的建好了 |
| MEMORY.md 内容太少 | 至少写 10 行有信息量的内容 |
| AGENTS.md 里没写"先读记忆" | 这是最隐蔽的坑，笔记本放在桌上它看都不看 |
| BOOTSTRAP.md 没删 | 初始化完成后应该删掉，不然每次醒来都重新走引导 |
| memory_search 返回 disabled | Embedding 服务没配置，参考 OpenClaw 文档配置 |

---

## 终极验证：跨会话测试

1. 跟龙虾聊点有信息量的内容
2. 等它写完日志后，**开一个新会话**
3. 问它："我上次跟你说了什么？"

- 能准确回忆 → 恭喜，你的龙虾不再是金鱼了 🎉
- 一脸茫然 → 回到上面的排查清单重新检查

---

## 一句话总结

> **小龙虾的智商是大模型给的，你改不了。但它的记忆是你管的。**
>
> 管得好，它就是越用越懂你的老员工。
> 管得烂，它就是每天失忆的实习生。
