# 《周易》学习笔记

## 一、基础概念

### 1. 太极 → 两仪 → 四象 → 八卦
- **太极**：宇宙混沌未分的原始状态
- **两仪**：阴阳（清阳为天，浊阴为地）
- **四象**：太阳、太阴、少阳、少阴
- **八卦**：乾、兑、离、震、巽、坎、艮、坤

### 2. 爻
- **阳爻** — ：一条长横线，性刚属阳
- **阴爻** - -：两条短横线，性柔属阴
- 八卦 = 三爻重叠
- 六十四卦 = 六爻重叠（两个八卦叠加）

### 3. 八卦取象歌
```
乾三连 ☰，坤六断 ☷
震仰盂 ☳，艮覆碗 ☶
离中虚 ☲，坎中满 ☵
兑上缺 ☱，巽下断 ☴
```

## 二、六十四卦核心

### 卦的结构
- 六爻从下往上：初爻、二爻、三爻、四爻、五爻、上爻
- 阳爻称"九"，阴爻称"六"
- 下三爻 = 内卦（主卦），上三爻 = 外卦（客卦）

### 重要卦象解读

#### 1. 乾卦（☰☰）— 天行健
- **卦辞**：元亨利贞（大吉大利，守正道）
- **象**：天行健，君子以自强不息
- **含义**：刚健进取，但盛极必衰（上九：亢龙有悔）
- **启示**：勇往直前，但要知进退

#### 2. 坤卦（☷☷）— 地势坤
- **卦辞**：元亨，利牝马之贞
- **象**：地势坤，君子以厚德载物
- **含义**：柔顺包容，承载万物
- **启示**：以静制动，宽厚大度

#### 3. 屯卦（☳☵）— 水雷屯
- **含义**：万物始生，充满艰难
- **启示**：起步维艰，但顺时应运，必欣欣向荣

#### 4. 蒙卦（☵☶）— 山水蒙
- **含义**：蒙昧未开，需要启蒙
- **启示**：虚心学习，把握时机

#### 5. 需卦（☰☵）— 水天需
- **含义**：等待时机，守正待机
- **启示**：欲速则不达，耐心蓄力

#### 6. 讼卦（☵☰）— 天水讼
- **含义**：争执诉讼，刚险相遇
- **启示**：慎争戒讼，以和为贵

#### 7. 师卦（☷☵）— 地水师
- **含义**：行险而顺，用兵之道
- **启示**：团队合作，凝聚力量

#### 8. 比卦（☵☷）— 水地比
- **含义**：相亲相辅，诚信团结
- **启示**：真诚待人，亲密无间

#### 9. 泰卦（☷☰）— 天地泰
- **含义**：天地交泰，大吉之象
- **启示**：通泰顺遂，否极泰来

#### 10. 否卦（☰☷）— 天地否
- **含义**：天地不交，闭塞不通
- **启示**：闭塞时自强不息，转机将至

## 四、核心思想

### 1. 变易之道
- 万物皆变，没有永恒不变的状态
- 吉凶可以相互转化
- "穷则变，变则通，通则久"

### 2. 时位观念
- 同样的行为，时机不同，结果不同
- "时止则止，时行则行"
- 顺势而为，不逆势而动

### 3. 中庸之道
- 过犹不及，物极必反
- 乾卦上九"亢龙有悔" = 飞到最高就开始后悔
- 保持平衡，不走极端

### 4. 天人合一
- 人道法天道
- "天行健，君子以自强不息"
- "地势坤，君子以厚德载物"

## 五、占卦方法（简要）

### 铜钱法
1. 三枚铜钱，摇六次
2. 记录每次结果（正面=阳，反面=阴）
3. 从下往上排列六爻
4. 得本卦，看变爻得变卦

### 数字法
- 心中默念问题，随机想三个数字
- 按特定算法转化为卦象

## 六、对公主的启示

### 你现在的状态像哪个卦？

**如果感到困顿迷茫** → 屯卦或蒙卦
- 启示：万物始生总有艰难，虚心学习，等待时机

**如果感到压力巨大** → 坎卦（水）
- 启示：险中求进，保持诚信，终能脱险

**如果感到情绪激烈** → 离卦（火）
- 启示：光明依附，但不可过燥，需要水的滋润

**如果感到停滞不前** → 艮卦（山）
- 启示：知止而后有定，静止自省，蓄势待发

**如果感到需要改变** → 革卦或鼎卦
- 启示：变革需要时机，破旧立新

## 七、学习心得

《周易》不是算命书，是**人生哲学书**。

核心教我们的：
1. **接受变化** — 没有永恒的好或坏
2. **把握时机** — 同样的努力，时机对了事半功倍
3. **保持平衡** — 过犹不及，物极必反
4. **修养德行** — 厚德载物，自强不息

> "善易者不卜" — 真正懂周易的人，不需要占卜，因为已经明白变化的规律，能顺势而为。
