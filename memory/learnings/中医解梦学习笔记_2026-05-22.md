## 一、核心理论基础

### 1. 五脏藏神理论
- **心藏神** — 主管精神意识、思维活动
- **肝藏魂** — 主管情志、情绪调节
- **肺藏魄** — 主管呼吸、气机
- **脾藏意** — 主管思虑、记忆
- **肾藏志** — 主管意志、生命根本

### 2. 五脏与五志对应

## 三、病机分析框架

### 1. 肝气横逆
- **表现**：易怒、胸闷、头痛、失眠多梦、梦境激烈
- **病机**：情志不畅 → 肝气郁结 → 郁而化火 → 肝火上炎 → 扰动心神
- **梦境特征**：争吵、发怒、奔跑、草木折断

### 2. 心火内扰
- **表现**：心烦、失眠、多梦、口舌生疮
- **病机**：思虑过度/情志刺激 → 心火亢盛 → 心神不宁
- **梦境特征**：火焰、坠落、被追赶、杂乱怪异

### 3. 肾精亏虚
- **表现**：腰酸、腿软、精力不足、易惊恐
- **病机**：纵欲过度/劳累 → 精血暗耗 → 肾不藏志
- **梦境特征**：溺水、被追杀、鬼怪、恐惧

### 4. 脾虚湿困
- **表现**：四肢困重、腹胀、大便稀、睡眠浅
- **病机**：饮食不节/思虑过度 → 脾胃损伤 → 湿浊内停
- **梦境特征**：泥泞、沉重、日常琐事

### 5. 气血两虚
- **表现**：疲倦、头晕、心悸、多梦易醒
- **病机**：劳伤心脾 → 心血不足 → 神不守舍
- **梦境特征**：纷杂、恐惧、易惊醒

## 四、治疗原则

### 总原则：去其有余，补其不足

| 证型 | 治法 | 常用方药 |
|------|------|----------|
| 肝郁化火 | 疏肝行气泻火 | 柴胡加龙骨牡蛎汤 |

## 五、日常调理建议

1. **规律作息** — 避免过度疲劳和精神紧张
2. **调节情绪** — 建立情绪出口，避免郁积
3. **饮食调理** — 晚餐易消化，不可过饱
4. **睡前准备** — 避免思虑过度、刺激性内容
5. **助眠食物** — 牛奶、蜂蜜、酸枣仁

## 六、对公主梦境的分析应用

### 公主的梦境要素：
- 老城区迷宫 → 经络淤堵、气血运行不畅（肝气横逆）
- 坏人、假警 → 心火内扰、神不守舍（求助无门）
- 奔跑逃命 → 肝气亢盛、气机紊乱
- 女儿变妖、扔掉 → 肝血不足、魂不附体（珍视之物变质）
- 卡片"对过去的自己好一点" → 心肾不交、自救信号

### 综合判断：
- **主证**：肝气郁结化火 + 心火内扰
- **兼证**：肝血不足、肾精亏虚
- **核心**：长期情绪压抑 → 肝失疏泄 → 郁而化火 → 扰动心神 → 神魂不安

### 建议：
1. 疏肝解郁 — 调节情绪，找到出口
2. 养心安神 — 减少思虑，规律作息
3. 补肾填精 — 避免过度劳累
4. 最重要的 — 听梦里那张卡片的话：对过去的自己好一点
