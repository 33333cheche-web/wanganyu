**Day 3: 受想行识，亦复如是**

**原文：**
> 舍利子，是诸法空相，不生不灭，不垢不净，不增不减。是故空中无色，无受想行识，无眼耳鼻舌身意，无色声香味触法。
>
> ——《般若波罗蜜多心经》

**逐句拆解：**

**"是诸法空相"**
- "诸法" = 一切事物、一切现象
- "空相" = 空的本性、空的真相
- 不是"空的样子"，而是"空的本质"

**"不生不灭，不垢不净，不增不减"**
- 这三组"不"是心经最核心的否定句式
- "不生不灭"：没有开始，没有结束——超越时间
- "不垢不净"：没有脏，没有净——超越评判
- "不增不减"：没有多，没有少——超越数量
- 注意：不是"先有生然后灭"，而是本来就没有生灭这个概念

**"是故空中无色，无受想行识"**
- "是故" = 因此、所以
- 在空的境界里，连"色受想行识"五蕴都不存在
- 不是消灭它们，而是看透它们本来就是空的

**"无眼耳鼻舌身意，无色声香味触法"**
- 六根（感官）：眼耳鼻舌身意
- 六尘（对象）：色声香味触法
- 连"能感知的"和"被感知的"都是空的

**核心逻辑链：**
诸法空相 → 超越生灭垢净增减 → 五蕴皆空 → 六根六尘皆空

**今日要点：**
1. "不"不是否定存在，而是超越二元对立
2. 空不是"什么都没有"，而是"没有固定不变的自性"
3. 看透五蕴皆空，不是消灭感受，而是不被感受绑住

**记忆方法：**
三组"不"像三把钥匙：
- 不生不灭 → 打开"时间焦虑"
- 不垢不净 → 打开"好坏评判"  
- 不增不减 → 打开"得失计较"
