**Day 1: 心经 - 开篇**

**原文：**
> 观自在菩萨，行深般若波罗蜜多时，照见五蕴皆空，度一切苦厄。
>
> ——《般若波罗蜜多心经》

**逐句拆解：**

**"观自在菩萨"**
- 观自在 = 观世音菩萨
- "观" = 观察、观照，不是用眼睛看，是用智慧看
- "自在" = 自由无碍，不受任何东西绑住
- 合起来：一个已经达到"看什么都通透、什么都不卡"境界的觉悟者

**"行深般若波罗蜜多时"**
- "行" = 修行、实践，不是坐着想，是真的在做
- "深" = 深入的、彻底的，不是浅尝辄止
- "般若波罗蜜多" = 梵语，智慧到彼岸
- "时" = 当...的时候
- 合起来：当他深入实践这种"看透真相的智慧"的时候

**"照见五蕴皆空"**
- "照见" = 像灯照亮一样看见
- "五蕴" = 色、受、想、行、识——构成"我"的五个要素
- "皆空" = 都是空的，不是不存在，是不永恒、不独立

**"度一切苦厄"**
- "度" = 超越、渡过，不是"消灭"苦难
- 苦从哪里来？从"我觉得我不该苦"来
- 看透五蕴皆空，苦还在，但不再被它卡住

**核心逻辑链：**
深入智慧 → 看透五蕴皆空 → 超越一切苦难

**今日要点：**
1. "观自在"是状态，"行深般若"是方法，"照见五蕴皆空"是结果，"度一切苦厄"是效果
2. "空" = 没有固定自性，不是"没有"
3. 苦不是消灭的，是"看透后不再被绑"
