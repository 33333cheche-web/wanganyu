# 正向表达范式

## 概述

本文件回答一个问题：**这句话该怎么写得有力。**

它与 `banned-words.md` 互补：
- `banned-words.md` 告诉你**别这么写**（禁用词、慎用词、AI 句式黑名单）
- 本文件告诉你**该怎么写**（正向范式、动作动词、结果可见、承认边界）

**核心原则**（来自胡先煦采访 + cheche 真实对话）：
1. **直接、一句话一个判断** —— 不绕弯，不堆修饰
2. **力度来自事实，不靠修饰词** —— 用数字、角色、动作说话
3. **承认边界，不装全知** —— 说"已完成 A、待确认 B"而非"完全满足"
4. **保留原文的"人味"** —— 有力度原词不换成平庸书面语

---

## 一、直接表达（不绕弯）

### 原则
一句话一个信息点；结论在前，依据在后；不用"通过...实现...""在...的基础上..."这类空转结构。

### 对照表

| ❌ 绕弯表达 | ✅ 直接表达 |
|-----------|-----------|
| 通过深入分析并结合实际情况，我们发现… | 分析显示… |
| 在充分调研的基础上，团队制定了方案 | 团队完成调研，制定方案 |
| 经过多轮沟通与协调，最终达成一致 | 3 轮沟通后达成一致 |
| 通过技术手段实现数据打通 | 技术打通数据 / 完成数据对接 |
| 在保证质量的前提下按时交付 | 按时交付，质量达标 |

### 实测案例（凯西项目）

**原文**：
> 通过 WorkBuddy 系统的部署，实现了对 500+ 门店的全面覆盖，在此基础上建立起统一的管理口径。

**改后**：
> WorkBuddy 覆盖 500+ 门店，统一管理口径。

**减字率**：41 字 → 22 字，减 46%；信息无损。

---

## 二、动作优先（力度来自事实）

### 原则
用具体动作 + 可量化结果，不用"积极""努力""大力""深入"这类空转修饰。

### 动作动词白名单（优先使用）

| 类别 | 动词 |
|------|------|
| 执行 | 完成、交付、对齐、验证、落地 |
| 范围 | 覆盖、打通、接入 |
| 数据 | 召唤、留痕、沉淀 |
| 协作 | 同步、拉齐、确认 |
| 决策 | 确定、锁定、卡点 |

### 对照表

| ❌ 空转表达 | ✅ 动作 + 结果 |
|-----------|--------------|
| 团队积极推进项目落地 | 团队完成 3 轮需求确认，已交付原型 |
| 大力开展培训工作 | 完成 5 场培训，覆盖 200+ 人 |
| 努力实现数据互通 | 打通 3 个系统的数据接口 |
| 深入推进业务协同 | 大区经理 + 3 名 SFE 完成业务对齐 |
| 不断优化用户体验 | 优化 7 个核心流程，响应时间降低 30% |

### 实测案例（联运盒子项目）

**原文**：
> 培训团队积极推进课程体系建设，通过不断优化课程内容，努力提升学员满意度。

**改后**：
> 培训团队完成 12 门课程开发，学员满意度从 72% 提升至 89%。

**要点**：
- "积极推进" → "完成 12 门课程开发"（具体动作 + 数字）
- "不断优化" → 删（信息空转）
- "努力提升" → "从 72% 提升至 89%"（可验证结果）

## 三、结果可见（数字 + 角色 + 动作）

### 原则
主语明确到角色（岗位/部门/系统名），不写"相关人员""团队成员""大家"；结果写成可核对的具体值。

### 对照表

| ❌ 模糊主语 + 空结果 | ✅ 明确角色 + 可见结果 |
|-------------------|---------------------|
| 相关人员积极配合 | 大区经理 + 3 名 SFE 完成数据对齐 |
| 团队成员共同努力 | 产品经理、技术负责人完成需求评审 |
| 大家齐心协力推进 | 5 个部门完成流程拉齐 |
| 系统运行良好 | 系统稳定性达 99.8%，日均处理 5000+ 单 |
| 取得显著成效 | 转化率提升 23%，客单价增长 15% |

### 实测案例（三贵情史项目）

**原文**：
> 在各方的共同努力下，项目取得了良好的市场反馈。

**改后**：
> 上映 10 天，票房 1.2 亿，豆瓣评分 7.8。

## 四、承认边界（不装全知）

### 原则
不写"完全满足""全面覆盖""彻底解决"；明确说"已完成 A、待确认 B"或"覆盖 X、未覆盖 Y"。

### 对照表

| ❌ 装全知 | ✅ 承认边界 |
|---------|-----------|
| 完全满足客户需求 | 满足客户提出的 5 项核心需求；剩余 2 项待确认 |
| 全面覆盖业务场景 | 覆盖 80% 核心场景；长尾场景分期支持 |
| 彻底解决痛点 | 解决 3 个主要痛点；1 个痛点需系统升级后处理 |
| 完善的培训体系 | 培训体系覆盖岗前、在职、晋升 3 个阶段 |
| 全方位支持 | 提供技术支持 + 运营支持；业务咨询按需付费 |

### 实测案例（凯西项目）

**原文**：
> WorkBuddy 全面满足凯西的业务需求，彻底解决了管理痛点。

**改后**：
> WorkBuddy 满足凯西 5 项核心需求（实时数据、统一口径、移动端接入、权限分级、留痕审计）；高级分析功能待二期开发。

**要点**：
- "全面满足" → 列出具体 5 项需求
- "彻底解决" → 明确"高级分析功能待二期"（承认边界）

## 五、禁止平庸化替换

### 原则
有力度的原词（尤其是术语/产品词/用户钦定说法）**不换成平庸书面语**，即使后者"更书面"。

### 禁止替换清单

| 原词（有力度） | 禁止改成（平庸） | 适用场景 |
|--------------|----------------|---------|
| 打通 | 实现连接、建立通道、对接 | 系统集成、数据互通 |
| 召唤 | 调用、触发、启动 | 产品功能描述 |
| 卡点 | 关键环节、难点、瓶颈 | 问题诊断 |
| 留痕 | 记录、存档、保存 | 合规审计 |
| 实战 | 实际操作、实践环节 | 培训场景 |
| 口径 | 标准、规范、准则 | 管理统一 |
| 拉齐 | 对齐、统一、一致 | 团队协作 |
| 沉淀 | 积累、汇总、整理 | 知识管理 |

### 功能位豁免（标题、承诺、行动召唤）

这些功能位**优先保留冲击力**，允许省略主语、使用对比句式：

| 功能位 | 原文示例 | 禁止改成 | 理由 |
|-------|---------|---------|------|
| 标题 | 不是培训，是实战 | 并非传统培训，而是实战演练 | 损失冲击力 |
| 承诺 | 我们承诺 7×24 响应 | 沃橙承诺 7×24 响应 | 承诺位允许第一人称 |
| 行动召唤 | 立即体验 | 欢迎立即体验 | 增加冗余 |
| 副标题 | 5 年沉淀，500+ 门店验证 | 经过 5 年积累，已覆盖 500+ 门店 | 副标题允许精简 |

### 实测案例（凯西项目）

**原文**：
> 打通 3 个核心系统，实现数据实时召唤

**错误改法**：
> 实现 3 个核心系统的连接，支持数据实时调用

**正确做法**：
> 保持原文不动（"打通""召唤"是产品术语，有力度）

## 六、案例汇总（真实改稿）

### 案例 1：联运盒子推文 v3（2026-10-19）

**原文**：
> 通过系统化的培训体系建设，帮助企业全面提升员工能力，最终实现业务目标。

**问题**：
1. "通过...实现..." 绕弯
2. "系统化""全面" 空转修饰
3. "帮助企业" 主语模糊
4. "最终实现业务目标" 结果不可见

**改后**：
> 培训体系覆盖岗前、在职、晋升 3 个阶段；学员留存率从 65% 提升至 82%，业绩达标率提升 28%。

**改动要点**：
- 删"通过...实现..." 结构
- "系统化的培训体系" → "培训体系覆盖 3 个阶段"（具体范围）
- "帮助企业全面提升" → "学员留存率 / 业绩达标率"（可验证指标）
- 增加具体数字

---

### 案例 2：凯西经营大脑方案（标题改动）

**原文**：
> 构建统一的数据管理平台

**问题**：
- "构建" 太书面、无力度
- "统一的数据管理平台" 太长、信息密度低

**改后**：
> 打通 3 个系统，统一管理口径

**改动要点**：
- "构建" → "打通"（有力度的动作动词）
- "统一的数据管理平台" → "统一管理口径"（结果导向）
- 增加"3 个系统"（可验证范围）

---

### 案例 3：沃橙推文（承认边界）

**原文**：
> 完全解决企业培训痛点

**问题**：
- "完全" 装全知
- "培训痛点" 不具体

**改后**：
> 解决 3 个主要痛点：内容碎片化、效果难追踪、成本不可控

**改动要点**：
- 删"完全"
- 列出具体 3 个痛点（可验证）

## 七、执行检查清单

改稿时每条改动过一遍：

- [ ] **直接表达**：有没有"通过...实现...""在...基础上..."？能否改为"动作 + 结果"？
- [ ] **动作优先**：有没有"积极""努力""大力""深入"？能否换成动作动词白名单里的词？
- [ ] **结果可见**：主语是否明确到角色？结果是否可量化？
- [ ] **承认边界**：有没有"完全""全面""彻底"？能否改为"已完成 A、待确认 B"？
- [ ] **禁止平庸化**：有没有把"打通"改成"实现连接"、把"召唤"改成"调用"？若有，恢复原词。
- [ ] **功能位豁免**：标题、承诺、行动召唤是否保留了冲击力？
