# 通用 AI 句式黑名单（第三层判据 · 完整清单）

> 本文件是**第三层判据的明细**。三层优先级见 `edit-discipline.md` 零节。
> 一句话定位：**除了"我不喜欢的词"（第二层，见 `banned-words.md`），还有一批句式是 AI 的通病，与个人偏好无关。**
>
> 来源：开源项目 **lieflat-less-ai-tone**（MIT，`github.com/larashero3-dotcom/lieflat-less-ai-tone`）。
> 它的规则在 300 篇 AI 样本（117.9 万汉字，5 个模型）与人类对照语料上逐条实测过，
> 只收录"AI 显著多于人类、且人类侧稳定"的特征——**看着像 AI 味但测不出来的，它自己删掉了**（见第三节）。
> 本文件把它的规则拆成**可直接扫的词面清单**，并逐条标注方案体裁下的处置。

---

## 一、收录的 11 类（按"动作家族"组织）

> 每条格式：**触发词面**（可直接写进脚本）→ **它在干什么** → **改法** → **方案体裁处置** → **实测倍率**。
> 倍率是「AI ÷ 人类」，大于 1 才说明 AI 用得多。

---

### 1. 翻案腔

**触发词面**

| 家族 | 词面 |
|---|---|
| 对立式 | 不是……而是…… · 并非……而是…… · 不在于……而在于…… · 不是 A，是 B |
| 递进换皮 | 不只是……更要…… · 不仅……更…… · 远不止是…… · 无非是…… |
| 对照式 | 表面……实际…… · 看似……实则…… · 与其说……不如说…… |
| 预设立场 | 你以为……其实…… · 回头才发现…… · 说到底…… · 答案恰恰相反 · A 不重要，重要的是 B |

**它在干什么**：先立一个读者并没有的误解，再把它推翻。方案里读起来像在辩解。

**改法**：直接从正面下判断——先给判断，再给依据。只有文章确实用材料走过了"从误解到修正"的过程，才允许写自我修正，且不能套用上面的固定句式。

```
❌ 真正的壁垒不是技术，而是认知。
✅ 真正的壁垒是认知。

❌ 我们需要的不是更多的数据，而是更好的判断力。
✅ 我们需要的是更好的判断力。

❌ 你以为用户在乎功能多少，其实他们只在乎能不能马上用。
✅ 用户首先在乎能不能马上用。
```

**方案体裁处置**：**限量收（本技能 A 级项，且认所有换皮）**。
这一条与 `banned-words.md` 的 A 级「不是……而是……」是同一个动作，通用规则的贡献在于**把换皮认全**——「不只是……更要……」也在内。

> **⚠ 用量纪律（2026-10-16）**：本家族**不是绝对禁用，而是限量**——默认直接说后半句，
> 确有必要时才用，**全篇只留 1 处（长稿不超过 2 处）**，不要到处都用。
> "必要"的三条判据（稻草人 / 对立面是否真实 / 位置是否关键）与"没必要"的四种情形，
> 见 `banned-words.md` 的「用量条款」。换皮一律不算必要。

**实测**：AI 0.73 / 人类 0.22，**3.4×**。

### 2. 顿号罗列过密

**触发词面**：一个分句内出现两个以上顿号，串起三项以上并列成分。

**它在干什么**：一句话里塞进一整份清单，读起来在凑数。

**改法**：能概括就别逐项列举；必须保留三项以上时，改变其中一项的句法，不让它们排成同一结构。**不得改动原有列表结构，也不得删掉必要项目。**

```
❌ 采集、存储、展示。
✅ 从采集到展示。

❌ 无论是初创公司、中型企业，还是大型集团，都能从中受益。
✅ 各种规模的公司都能用。
```

**方案体裁处置**：**豁免范围必须按方案体裁重划**——目录索引、交付物清单、场景清单、字段清单、章节导航**一律保留**，这些是方案的信息载体。
实测：同一规则在 64 页方案上命中 **129 处**，抽样全部属于上述豁免类型。**脚本默认不报。**

**不改**：材料本身必须完整列出时（法规条目、配置项清单、财务科目）。

**实测**：AI 3.21 / 人类 1.78，1.8×（AI 侧偏高，但两类文本的清单密度天然不同）。

### 3. 相邻句结构同款

**触发词面**：相邻两句以上，逗号数量相同、成分顺序相同、长度接近。典型是"主语＋动词＋宾语，＋补充说明"连续复现。

```
❌ 这个功能上线后用户反馈很好。团队的开发效率提升明显。下一步的优化方向已经确定。
✅ 这个功能上线后用户反馈很好，团队开发效率也提升了。下一步优化什么，已经定了。
```

**它在干什么**：单看每句都通顺，连起来像在填表。

**改法**：打散其中一句的句法（合并、拆分、换语序、改短句）。只改句子内部，不动段落顺序，不删信息。

**方案体裁处置**：**不适用，明令保留**。方案的**结构对仗**是刻意设计（四组组名同长、副题同句式「从 X，到 Y」），属于本方核心资产。
**脚本默认不报。**

**实测**：每百段 AI 9.41 / 人类 4.81，**2.0×**（人类语料内部很稳定，不是体裁造成的）。

### 4. 破折号滥用

**触发词面**：`——` 用作停顿后的揭晓，或插入不必要的补充。

**改法**：直接写完整句子，或改用逗号、句号。

```
❌ 答案其实很简单——专注。
✅ 答案是专注。
```

**方案体裁处置**：**需重划豁免**。保留"标题 —— 并列清单"这种**排版用法**（用破折号引出下挂的清单）。
脚本已能自动区分：后文 24 字内出现两个以上顿号，判为排版用法，保留。

**实测**：AI 2.38 / 人类 0.80，**3.0×**（分模型差得远：DeepSeek 5.16、Claude 4.25、Gemini 0.51、GPT 0.11）。

### 5. 冒号滥用

两种形态，都是让冒号替自己说话。

#### 5a 提示语引出内容

**触发词面**：冒号前是「一句话总结 / 简单说 / 小结 / 结论 / 核心是 / 关键在于 / 重点是 / 原因是 / 问题是 / 答案是 / 本质是 / 具体来说 / 换句话说 / 也就是说 / 建议是」这类提示语。

**改法**：提示语本身不承担信息时删掉它，直接写内容；提示语在承接上文时保留，只把冒号换成句号或逗号。

```
❌ 一句话总结：这个方案成本太高。
✅ 这个方案成本太高。

❌ 核心是：先解决支付失败的问题。
✅ 先解决支付失败的问题。
```

**实测**：AI 0.29 / 人类 0.08，**3.8×**（人类两组都接近零，稳定）。

#### 5b 空转句引出列表

**触发词面**：正文里一行以冒号结尾，紧接着是列表项或编号，**且这句话去掉后信息不减**。

```
❌ 我见过的几种典型场景：
✅ 这几种场景我都见过。

❌ 一套基础检查通常包括：
✅ 基础检查通常包含这几项。
```

**改法**：把这句话本身写成有内容的判断，或直接删掉让列表接上上文。**不能删列表项。**

**实测**：AI 0.29 / 人类 0.03，**9.4×**（各个人类组都接近零，是全部规则里最强的一条）。

**方案体裁处置**：**两条都收**。方案里同样显得空转。

**不改**：引出人物直接原话（"他说：'明天再谈。'"）；小标题里的冒号；列表项内部的冒号；句中总说分说（"人擅长的是：判断业务逻辑"，GB/T 15834 认可的规范用法，且人类内部用量差 6.6 倍，测不出来源）；网址、代码、机器字段。

### 6. 序数词当小标题

**触发词面**：小标题（`#` 开头，或独立成行的加粗文本）以「一、二、三」或「第一、第二」编号，且连续三个以上。

**改法**：**删掉编号，保留小标题原有文字**。不能改小标题的措辞、顺序或层级。

```
❌ ## 一、先别急着写 prompt，先找出模糊在哪里
✅ ## 先别急着写 prompt，先找出模糊在哪里
```

**方案体裁处置**：**需重划豁免**——保留章节编号（`01 / 02 / 03`）与承担指代功能的编号（"见第三节"）。**脚本默认不报。**

**不改**：正文里的"首先……其次……最后"（实测与人类无差异）；Markdown 有序列表（`1.` `2.`）；只有一两个编号、没构成通篇编号的。

**实测**：AI 0.19 / 人类 0.06，3.1×。

### 7. 拟人化喻体

**触发词面**：「像 / 相当于 ＋ 一个 / 一位 ＋ 职业角色（导师、秘书、助手、顾问、管家、审查员、实习生……）」，且喻体带褒义修饰（"智慧的""永不疲倦的""全能的"），或后接"不仅……更……"。

```
❌ 它就像一位智慧的导师，不仅传授结论，更传授看待世界的多元视角。
✅ 它不只给结论，也讲看待问题的不同角度。

❌ 这相当于为团队配备了一个永不疲倦、秒级响应的初级审查员。
✅ 它不会疲倦，响应在秒级，能承担初级审查的活。
```

**改法**：换成这东西实际做了什么，或改用一个具体的人当喻体。

**方案体裁处置**：**不适用**。方案体里基本不用比喻。**脚本默认不报。**

**不改**：比喻本身（人类是 AI 的 2.4 倍）；具体的人当喻体（"像一个老师傅"）；喻体带来了正文没给的理解时。

**实测**：AI 0.018 / 人类 0.002，**7.3×**（带"永不／智慧的／全能的"修饰时差到 12.6×）。

### 8. 把已有的具体数据写回概括表述

**触发词面**：句中用「显著提升 / 大幅增长 / 明显改善 / 效率的提升 / 大量 / 众多」等概括说法，而同段或相邻段里**已经写着对应的具体数值、时间或对象**。

```
❌ 新系统实现了效率的提升。处理时间从两小时缩短到四十分钟。
✅ 新系统把处理时间从两小时缩短到四十分钟。
```

**改法**：把原文已有的具体值提到概括词的位置。**原文没有具体数据时，只恢复动词，不许自己编数字。**

**方案体裁处置**：**收，且与本技能"数字落地、力度来自事实"同向。**

**不改**：原文确实只有概括、没有具体材料时。这时不能补，也不能因为"太抽象"就删掉句子。
**结构对仗的组名与副题不受本条约束**——如四组副题里的「效率提升」，它是刻意设计的结构，不构成"用概括词盖住具体值"。
（实测：脚本若把「效率提升」当触发词面，在样本项目里命中 3 处**全部是此类结构**，误报率 100%，故词面已收紧到"显著提升 / 大幅增长"这一档。）

**实测**：数字密度 AI 6.34 / 人类 17.92，**人类是 2.8 倍**（这是覆盖面最广的一项差异）。

### 9. 禁用起手式

**触发词面**：说白了 · 说穿了 · 先说结论 · 先说重点 · 直接说结论

```
❌ 说白了，这个项目没有足够的预算。
✅ 这个项目预算不足。
```

**改法**：删掉起手式，直接给判断。

**方案体裁处置**：**收。**

**实测**：AI 0.025 / 人类 0.008，3.2×。

### 10. 翻译腔（只保留五种）

> 作者原本筛了 **18 种**翻译腔写法，实测后只剩 5 种够格。其余 13 种低于收录门槛，**明确不作为改写理由**（见第三节）。
> 现代汉语书面语早已吸收大量译文句式，被动句、名词化、长句都是正常中文写作。

| # | 触发词面 | 改法 | AI 每千字 | 人类倍率 |
|---|---|---|---|---|
| 10a | **过长前置定语**：中心名词前修饰成分超 15 字，或"的"连续出现两个以上 | 在原段落内拆成两个分句 | 0.42 | 收录 |
| 10b | **"当……时"前置时间从句**：句首"当"、以"时，"收尾，中间一个完整主谓 | 删掉"当"和"时"，让从句直接作前一分句 | 0.26 | 收录 |
| 10c | **前置话题壳**：句首"对于……来说""对……而言""就……而言""关于……""在……方面"，而后面的句子本来就以这个对象为主语或宾语 | 把对象直接放到主语或话题位，删掉壳子 | 0.22 | 收录 |
| 10d | **句首连接词当路标**：段首或句首"然而""因此""此外""与此同时""换言之""总而言之"，尤其相邻段落连续这样开头 | 把连接词移到主语后面 | 0.18 | 收录 |
| 10e | **"这意味着"式复述句**：一句以"这意味着""这表明""这说明""换句话说"开头，且后面内容与前一句同义 | 并入前一句，或删掉提示语只留结论 | 0.15 | 收录 |

```
❌ 这是一个能够让团队在不增加人力的情况下显著提升审核速度的工具。
✅ 这个工具能显著提升审核速度，不需要增加人力。

❌ 当所有人都能用 AI 写文章时，内容本身就不再是竞争优势。
✅ 所有人都能用 AI 写文章，内容本身就不再是竞争优势。

❌ 对于早期团队来说，招人是最难的事。
✅ 早期团队最难的事是招人。

❌ 然而，这个方案并不适用于所有场景。
✅ 这个方案其实不适用于所有场景。

❌ 留存率涨到了 72%。这意味着产品找到了 PMF。
✅ 留存率涨到 72%，产品找到了 PMF。
```

**方案体裁处置**：**五种都收**，且与本技能"主语不省"的要求同向。

**不改**：10b 中句子确实需要标示时点、删掉后时间关系变模糊时；10b 的"的时候"（实测 0.02/千字，不是 AI 特征）；10c 中确实需要限定讨论范围、删掉会被读成全局断言时；10d 中论证确实需要在段落转折处立一个显式路标时；10e 中后面确实给出了前句推不出的新结论时。
**专业术语、法律文本、公文固定表达和已有固定译法不受影响。**

### 11. 段首零主语评论

**触发词面**：**非首段**以「听起来 / 看起来 / 看上去 / 听上去 / 说到底 / 换句话说 / 意味着 / 值得注意的是 / 不难看出 / 细看 / 再看 / 回过头看 / 问题在于 / 原因在于 / 结果是 / 有意思的是 / 更重要的是 / 关键在于 / 真正的」等评论语开头，**且整句没有"这／那／其／此／上面"等回指上文的成分**。

```
❌ 听起来像一条功能描述，其实底下换掉了一样更根本的东西。
✅ 这听起来像一条功能描述，其实底下换掉了一样更根本的东西。

❌ 值得注意的是，配置数据本来就按"这是谁的"分层放着。
✅ 这一点值得注意，配置数据本来就按"这是谁的"分层放着。
```

**改法**：**补一个回指词，或点明评论对象**。多数情况加一个"这"字就够。不改段落顺序，不动段内其他文字。

**方案体裁处置**：**收**。方案里常见"值得注意的是"式起段。

**不改**：首段（没有上文可指）；原文已有回指成分时；对话和引语内部。

**实测**：占非首段 AI 0.61% / 人类 0.14%，**4.4×**。
（问题不在"不用衔接词"——段首衔接词总量人类 15.1%、AI 14.4%，几乎一样；问题在评论句省掉了回指成分。）

## 二、本技能另收的条目（属于第二层，不是通用规则）

这几条通用规则**测不出来**，但本方文风另有要求。它们的依据是个人偏好（第二层），放在这里是为了让脚本能扫到，**不代表它们是通用 AI 痕迹**。

| 条目 | 通用实测 | 本方为什么仍收 | 层级 |
|---|---|---|---|
| **名词化 / 轻动词**（"完成了对……的优化""实现了……的提升""进行了……的分析"） | AI 0.003 / 人类 0.005，**人类更多**，作者已删 | 本方风格第 9 条「动词选准」、第 4 条「力度来自事实」——动词直接说事，比套一层名词结构有力 | 第二层 |
| **程度直译**（在某种程度上 / 一定程度上 / 从某种意义上说 / 在很大程度上 / 相对而言） | 0.02/千字，**低于门槛**，作者已删 | 本方风格第 3 条「精炼」——空转修饰，删掉不减信息 | 第二层 |
| **复数硬译**（一系列的 / 各种各样的 / 诸多） | 0.00/千字，作者已删 | 同上，属冗余修饰 | 第二层 |

> **这一节解释了"为什么同一个词，在别处不算问题、在我们这儿要改"**：
> 第二层（个人文风）允许严于第三层（通用规则）。
> 判据不同，不矛盾——冲突时按优先级裁决，不合并成一套。

## 三、不收录清单（看着像 AI 味，实测站不住）

> 以下特征在通用"去 AI 味"攻略里常被点名，**实测与人类写作无差别，不能据此改文字**。
> 这张表和判据一样是硬约束。来源为作者的实测数据（列在"实测"栏）。

| 特征 | 常见说法 | 实测 | 结论 |
|---|---|---|---|
| 句长均匀度 | "AI 均匀度是人类 50 倍" | 句长 CV AI 0.58 / 人类 0.67 | 原数据是切句缺陷造成的假象。**不要为造节奏拆句** |
| 相邻句长差 | 同上 | AI 21.7 / 人类 21.7 | 完全无差异 |
| 段落长度均匀度 | "AI 段落极均匀" | 稳健离散度 0.94 / 1.00 | CV 3.9 倍源于一个未分行长段 |
