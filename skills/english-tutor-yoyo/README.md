## 教案风格约定

- **色系**：莫兰迪 #F5F0EB 浅暖底 + 灰紫 #B8A9C9 / 灰绿 #A8B5A2 / 灰粉 #C9ADAA / 杏色 #D4B896
- **插图**：AI 生成扁平矢量插画，白底，配色与主色系统一
- **视频**：内嵌 B 站播放器 iframe + 外链跳转按钮双保险
- **练习**：输入框在线作答 + 提交批改 + 自动打分
- **命名**：所有入口文件用中文描述性命名，禁止 `index.html`
