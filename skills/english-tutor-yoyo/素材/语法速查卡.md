# 语法速查卡

> 生成每日教案时，从本表选取当日知识点对应的卡片内容放入讲义。

---

## 卡 1：be 动词

```
口诀：我用 am，你用 are，is 跟着他她它。
      单数名词用 is，复数名词全用 are。

否定：be 后面加 not → isn't / aren't
疑问：be 提到句首 → Is he...? / Are you...?
```

---

## 卡 2：人称代词

```
主格（动词前）：I / you / he / she / it / we / they
宾格（动词/介词后）：me / you / him / her / it / us / them
```

---

## 卡 3：物主代词

```
形物代（后跟名词）：my / your / his / her / its / our / their
名物代（独立使用）：mine / yours / his / hers / its / ours / theirs
公式：mine = my + 名词
特例：his 和 its 形名同形
```

---

## 卡 4：冠词

```
a / an：看发音不看字母
  a university（u 发 /juː/，辅音）
  an hour（h 不发音，元音开头）

the：特指
  ① 双方都知道 → Close the door.
  ② 上文提过 → I have a dog. The dog is black.
  ③ 独一无二 → the sun / the moon

零冠词：三餐 / 球类 / 星期 / 月份 / 泛指复数
```

---

## 卡 5：名词复数

```
规则变化：
  一般 +s       → books
  s/x/sh/ch +es → boxes
  辅音+y → ies  → babies
  f/fe → ves    → knives
  有生命 o +es  → tomatoes

不规则：
  man→men   woman→women   child→children
  mouse→mice  foot→feet  tooth→teeth
  sheep→sheep  fish→fish  Chinese→Chinese
```

---

## 卡 6：一般现在时

```
结构：主语 + 动词原形/三单
三单规则：一般 +s / s,x,sh,ch,o +es / 辅音+y → ies
关键词：always, usually, often, sometimes, never, every day

否定：don't/doesn't + 动词原形
疑问：Do/Does + 主语 + 动词原形...?
```

---

## 卡 7：现在进行时

```
结构：am/is/are + 动词-ing
现在分词：一般 +ing / 去 e +ing / 双写 +ing
关键词：now, look, listen, at the moment

常错：be 动词不能丢！
  He playing → He IS playing ✓
```

---

## 卡 8：一般过去时

```
规则：动词 +ed（-ed 三种读法：/t/ /d/ /ɪd/）
否定：didn't + 动词原形（有了 did，动词变回原形！）
疑问：Did + 主语 + 动词原形...?

不规则动词分三组背：
  AAA: cut-cut-cut, put-put-put
  ABB: buy-bought-bought, think-thought-thought
  ABC: go-went-gone, see-saw-seen, eat-ate-eaten
```

---

## 卡 9：There be 句型

```
There is + 单数/不可数
There are + 复数

就近原则：There is a book and two pens.
疑问：Is there...? / Are there...?
```

---

## 卡 10：介词速记

```
时间：at 点 / on 天 / in 月季年
  at 7:00 / on Monday / in July

方位：
  in（里面） on（上面接触） under（下面）
  behind（后面） in front of（前面）
  next to（旁边） between（两者之间）
```

---

## 卡 11：比较级与最高级

```
规则：+er/+est → bigger/biggest
多音节：more/most → more beautiful/most beautiful
不规则：good→better→best, bad→worse→worst
同级：as + 原级 + as → as tall as
```

---

## 卡 12：现在完成时

```
结构：have/has + 过去分词
用法：已经做了 / 过去对现在有影响
注意：不跟具体过去时间连用
  I have done it yesterday ✗
```

## 使用说明

每次生成 Day N 教案时，查阅当天知识点对应的速查卡，将口诀和关键规则融入讲义页面。
