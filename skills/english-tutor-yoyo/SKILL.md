为学生「悠悠」生成每日英语补习教案。触发：用户提到「做Day N教案」「下一课」「继续做教案」或类似指令。

- 考试：100 分卷 | 当前：约 50 分 | 目标：80 分 | 每日：90 分钟

## 工作区

所有文件在 `D:\cheche\英语补习\`，使用前先读取目录下的 README.md 和素材文件。

## 教案生成流程

收到「做 Day N 教案」指令后，执行以下步骤：

### Step 1：确定知识点

查阅 `D:\cheche\英语补习\英语语法学习计划_七升八.md`，找到当天应教学的知识点列表。如计划中无精确到天的安排，则按计划中该周主题自行拆解。

### Step 2：收集素材

- 从 `素材/B站课程链接.md` 选取 1-2 个匹配视频，确认 aid + page 编号
- 从 `素材/语法速查卡.md` 选取对应速查卡内容
- 如需补充词汇，从 `素材/必背词汇.md` 提取

### Step 3：生成教案文件

在 `教案/WeekN/` 下创建以知识点命名的文件夹（如 `Day2_冠词`），生成以下内容：

**a) 10 页左右的 HTML 幻灯片套件**，参考 Day1 模板风格：

- 01-title.html — 标题页（知识点名 + 核心问题）
- 01b-前置视频.html — B 站视频嵌入页（iframe + 外链按钮）
- 02-review.html — 回顾旧知
- 03-concept.html — 概念引入
- 04-table.html — 核心对比表 / 规则表
- 05-formula.html — 公式 / 口诀 / 步骤
- 06-examples.html — 例题演示
- 07-mistakes.html — 常见错误
- 08-quiz.html — **在线交互练习**（输入框 + 提交批改 + 自动打分）
- 09-summary.html — 总结 + 口诀 + 作业提醒

**b) 一个中文命名的入口 HTML**（如 `Day2_冠词.html`），内含完整 deck manifest。

### 🔍 Step 3.5：内容复核（必须执行，不可跳过）

**教案涉及知识点——教错比不教更糟。** 生成完成后，逐项复核：

1. **语法规则**：逐条对照 `素材/语法速查卡.md` 或权威来源，确认每条规则、口诀、公式无误
2. **例题答案**：逐题验算，确保 08-quiz.html 中每道题的 `data-answer` 是唯一正确答案
3. **B站视频**：确认 aid + page 编号正确，内外链均可访问
4. **练习题数量**：≥ 6 道，覆盖填空和改错两种题型
5. **hint/placeholder**：确认不直接暴露答案，只指向规则思路

复核完成后，在回复中明确写出「已复核：规则 N 条 ✓ / 例题 N 道 ✓ / 视频链接 ✓」。

### Step 4：配图（可选，默认生成）

用 ImageGen 为以下 4 页各生成 1 张扁平矢量插画（白底、莫兰迪色系、教育主题），存入 `images/` 子目录：
- 封面 — 学习场景
- 概念 — 对比/比喻
- 错误 — 提醒/警示
- 总结 — 成就/奖杯

### Step 5：确认 + 展示

用 present_files 展示入口 HTML，并告知用户教学内容概要。

## 技术约定（强制遵守）

### 幻灯片架构
- 每页 1920×1080，独立 HTML，用 `assets/deck_index.html` 聚合逻辑
- 入口文件用中文描述性命名（如 `Day2_冠词.html`），**禁止** `index.html`

### 色系（莫兰迪）
- 背景 #F5F0EB | 卡片 #FFFFFF | 边框 #E8E0D5
- 灰紫 #B8A9C9 | 灰绿 #A8B5A2 | 灰粉 #C9ADAA | 杏色 #D4B896
- 主文字 #5D5A58 | 次要文字 #8B8682
- 字体 PingFang SC / Microsoft YaHei

### 已踩坑（生成新页面时必须注意）

1. **输入框焦点**：deck 的 `blur` 事件会抢 iframe 内输入框的焦点，必须修改为检测 `activeElement.tagName === 'IFRAME'` 时跳过
2. **练习题 hint/placeholder**：不能直接写成答案（如 placeholder 不能是 `my, yours`），提示要指向规则而非答案本身
3. **多词答案**：判题逻辑要对逗号分隔的答案做 trim + 乱序容错
4. **B 站嵌入**：iframe 可能有跨域限制，必须同时提供「在 B 站打开」的外链按钮

### 在线练习题规范

08-quiz.html 中：
- 用 `<input class="answer-input" data-answer="正确答案">` 存放答案
- 判题 JS 需包含：空值检测、单答案精确匹配、多答案逗号容错
- 提交后显示每题正误 + 总分 + 评语
